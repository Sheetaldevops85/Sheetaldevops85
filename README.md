#### 1. 🏛️ Tenant Hierarchy & Cloud Adoption Framework (CAF)
Designed and operationalized enterprise-scale Microsoft Entra ID tenant structures adhering strictly to the **Microsoft Cloud Adoption Framework (CAF)** lifecycle: *Plan ➔ Ready ➔ Adopt ➔ Govern ➔ Secure ➔ Manage*.

```
Tenant Root Group (Microsoft Entra ID)
├── Platform Management Group
│   ├── Connectivity Subscription (Hub VNet, Azure Firewall, ExpressRoute, VPN Gateway)
│   ├── Identity Subscription (Entra Domain Services, Key Vaults, Privileged Access)
│   └── Management Subscription (Log Analytics, Automation Accounts, Centralized Monitoring)
├── Landing Zones / Application Management Group
│   ├── Dev / Test Subscriptions (Automated cost budgets, auto-shutdown schedules)
│   ├── UAT Subscriptions (Pre-production staging, performance testing)
│   └── Production Subscriptions (Strict RBAC, PIM, Multi-Region DR, High Availability)
├── Sandbox Management Group (Isolated playground with non-routable CIDR, budget caps)
└── Decommissioned Management Group (Read-only / revoked access for retiring assets)
```

- **Enterprise Guardrails**: Enforced root-level and MG-level **Azure Policy & Initiatives** for CIS Azure Benchmarks, allowed locations, mandatory tags, encryption at rest, and SKU restrictions.
- **Subscription Lifecycle**: Automated subscription vending, onboarding, offboarding, and structured policy exemption workflows with documented risk justifications and review deadlines.
- **Identity & RBAC**: Fine-grained RBAC groups, Custom Roles, Entra ID Privileged Identity Management (PIM), and Just-In-Time (JIT) access.

#### 2. 🌐 Hub-and-Spoke Networking & Zero-Trust Defense
Engineered resilient, segregated network backbones preventing lateral threats and maintaining seamless hybrid datacenter interconnectivity.

- **IPAM & CIDR Strategy**: Comprehensive assessment of on-premises subnets to eliminate IP overlap across Hybrid ExpressRoute/VPN connections and cloud workloads.
- **Centralized Hub Architecture**: Dedicated Hub Virtual Network hosting Azure Firewall / Network Virtual Appliances (NVAs) for centralized east-west and north-south inspection with controlled egress.
- **Spoke VNet Topology**: Non-transitive peering between Hub and Spoke VNets with User Defined Routes (`0.0.0.0/0 -> Firewall IP`).
- **Private Access & Endpoints**: Complete elimination of public IPs for PaaS services using **Azure Private Endpoints** and auto-registered **Private DNS Zones**.
- **Defense-in-Depth Model**:
  - *Identity Level*: Entra ID, Conditional Access Policies, MFA, PIM.
  - *Networking Level*: NSGs, Application Security Groups (ASGs), Azure Firewall L4/L7 rules, UDR route tables.
  - *Governance Level*: Azure Policy auto-remediation, Microsoft Defender for Cloud posture scoring.
  - *Compute Level*: VM hardening, custom data / cloud-init scripts, OS patch baselines.

#### 3. ⚙️ Enterprise Terraform Landing Zone Automation
Implemented modular, highly scalable Infrastructure as Code (IaC) governance pipelines adhering to enterprise compliance standards.

- **Modular DRY Architecture**: Built centralized, reusable, version-controlled Terraform modules with strict input validation and semantic version tagging.
- **Remote State Security**: Secured state backends in Azure Blob Storage with customer-managed keys (CMK), TLS 1.3, soft delete, blob versioning, and least-privilege RBAC assignment.
- **Shift-Left Security & Quality Gate**:
  - `tflint` & `terraform fmt` for syntax and style validation.
  - `checkov` & `tfsec` static code analysis checking against CIS, NIST, and ISO27001 benchmarks.
  - `gitleaks` & `trufflehog` pre-commit hooks and pipeline stages to prevent secret leakage.
- **FinOps via IaC**: Integrated `infracost` in Pull Request pipelines providing automatic cloud cost difference breakdowns before merging.
- **Drift Detection**: Scheduled non-destructive pipelines executing `terraform plan -detailed-exitcode` to detect and alert on out-of-band portal changes.

#### 5. 📦 100+ Enterprise Application Cloud Migration
Led large-scale migration programs modernizing legacy monolithic and multi-tier architectures into secure, governed Azure environments.

<details>
<summary><b>🔍 Expand: End-to-End Migration Framework & Checklists</b></summary>

<br>

##### 1. Strategy & Discovery Phase
- **6-R Strategy Decision Tree**: Rehost (Lift & Shift via Azure Migrate), Replatform (PaaS transformation), Refactor (Containerization), Rearchitect, Retain, or Retire.
- **Discovery & Assessment**: Automated discovery of dependencies, CPU/RAM utilization baselines, IOPS demands, and storage sizing via Azure Migrate appliances.
- **Readiness & Gap Analysis**: Network latency validation, OS compatibility audits, database version compatibility, and firewall dependency mapping.

##### 2. Comprehensive Pre-Migration Checklist
- [x] On-Premises & Azure CIDR validation (No overlapping IP addresses).
- [x] Target Landing Zone subscriptions, resource groups, and NSGs pre-provisioned via Terraform.
- [x] ExpressRoute / Site-to-Site VPN bandwidth verified; QoS rules implemented.
- [x] Azure Site Recovery (ASR) replication healthy and sync delta under target thresholds.
- [x] Initial seed backup verified; backup retention policies configured.

##### 3. Cutover Window & During Checklist
- [x] Final delta synchronization executed on source databases and disks.
- [x] Maintenance window freeze communicated across stakeholders.
- [x] Test failover validation executed in isolated non-routable VNets.
- [x] Primary cutover triggered; DNS TTL decreased; Private DNS zones updated.
- [x] Middleware custom scripts run to verify application binding and backend DB connection strings.

##### 4. Post-Migration & Hypercare Checklist
- [x] Health checks, synthetic user transactions, and performance benchmarks validated.
- [x] Azure Monitor diagnostic settings enabled and routed to central Log Analytics Workspace.
- [x] Antivirus / Microsoft Defender for Cloud agents confirmed active and reporting.
- [x] Post-migration signoff obtained from Application Owners and Business stakeholders.
- [x] 24/7 Hypercare war-room activated for 14-day observation window.

</details>

#### 6. 💰 FinOps & Continuous Cost Optimization
Embedded financial accountability and active waste reduction across multi-subscription environments.

- **Proactive Cloud Hygiene**:
  - Automated detection and remediation of unattached managed disks, orphaned Public IPs, and idle App Service plans.
  - Compute right-sizing based on 30-day P95 CPU/memory metrics to downgrade oversized VMs.
  - Log Analytics workspace ingestion filtering: eliminated redundant debug and trace logs, reducing ingestion costs by **~30%**.
- **Automated Workload Scheduling**:
  - Implemented Azure Automation Runbooks / Logic Apps for scheduled automated shutdown and startup of Dev/UAT environments outside business hours.
- **Commitment & Rate Optimization**:
  - Strategic allocation of **Reserved Instances (1-Year / 3-Year RIs)** and **Azure Savings Plans** for steady-state workloads.
  - Storage lifecycle management moving cold data from Hot to Cool/Archive tiers.

#### 7. 🛡️ High Availability, Backup & Disaster Recovery (BCDR)
Engineered resilient, multi-region architectures delivering high availability and rapid disaster recovery SLAs.

- **Storage Resiliency**: Configured Locally Redundant (LRS), Zone-Redundant (ZRS), and Geo-Redundant (GRS/GZRS) replication strategies aligned with data criticality.
- **High Availability Workloads**: Deployed **Virtual Machine Scale Sets (VMSS)** across multiple Availability Zones with dynamic metric-based autoscale rules.
- **BCDR Architecture**:
  - Defined rigid **RTO (Recovery Time Objective)** and **RPO (Recovery Point Objective)** per business tier.
  - Automated disaster recovery orchestration via **Azure Site Recovery (ASR)** between Primary and Paired Secondary Regions.
  - Conducted scheduled, non-disruptive DR drills with automated recovery verification runbooks.
